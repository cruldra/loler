# 阵容配置器功能说明

## 功能概述

阵容配置器是一个用于配置和管理英雄联盟队伍阵容的工具。用户可以为两支队伍分别选择英雄，并保存配置以供后续使用。

## 主要功能

### 1. 阵容配置
- 支持两支队伍的配置（队伍1和队伍2）
- 每支队伍5名玩家，位置固定为：上单、打野、中单、ADC、辅助
- 为每个位置选择英雄
- 标记禁用英雄

### 2. 阵容管理
- 通过Modal弹窗保存阵容配置（输入名称和描述）
- 编辑已保存的阵容
- 删除阵容配置
- 查看所有已保存的阵容

### 3. 用户界面
- 直观的双栏布局，左右分别显示两支队伍
- 实时预览选择的英雄头像
- 位置固定显示，无需手动选择
- 响应式设计，支持移动端访问

## 使用方法

### 访问阵容配置器
1. 在导航栏点击"阵容配置"
2. 或直接访问 `/team-composition`

### 创建新阵容
1. 为每支队伍的各个位置选择英雄：
   - 从下拉列表中选择英雄
   - 英雄头像会自动显示
   - 可选：点击"×"标记为禁用
2. 点击"保存阵容"按钮
3. 在弹出的Modal中：
   - 输入阵容名称（必填）
   - 输入阵容描述（可选）
   - 点击"保存"按钮

### 编辑阵容
1. 在"我的阵容配置"列表中找到要编辑的阵容
2. 点击"编辑"按钮
3. 修改配置
4. 点击"保存阵容"按钮
5. 在Modal中确认保存

### 删除阵容
1. 在"我的阵容配置"列表中找到要删除的阵容
2. 点击"删除"按钮
3. 确认删除操作

### 重置配置
- 点击"重置"按钮可以清空当前所有选择

## 技术实现

### 数据库模型
- 表名：`team_compositions`
- 主要字段：
  - 基本信息：id, user_id, name, description
  - 队伍1配置：team1_player1-5的champion, role, banned
  - 队伍2配置：team2_player1-5的champion, role, banned
  - 时间戳：created_at, updated_at

### API端点
- `GET /team-composition` - 阵容配置页面
- `GET /team-composition?edit={id}` - 编辑阵容页面
- `POST /team-composition/save` - 保存阵容
- `POST /team-composition/{id}/delete` - 删除阵容

### 组件
- `templates/components/team_composition.html` - 阵容配置器组件
- `templates/team_composition.html` - 阵容配置页面

## 设计参考

本功能的UI设计参考了 `.superdesign/design_iterations/lol_bp_component_1.html`，采用了：
- 双栏布局展示两支队伍
- 清晰的视觉层次
- 流畅的交互动画
- 符合LOL主题的配色方案
- Modal弹窗保存方式（参考符文配置页面）

## 注意事项

1. 需要登录才能保存阵容配置
2. 每个用户的阵容配置相互独立
3. 英雄头像会根据选择自动更新
4. 禁用标记仅作为视觉提示，不影响保存
5. 位置固定为：上单、打野、中单、ADC、辅助，无需手动选择
